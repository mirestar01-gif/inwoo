# 인우테크 웹사이트 · 고객 포털 · 관리자 화면 (v0 시안)

복합기·프린터 렌탈 개인사업자 "인우테크"를 위한 공개 홈페이지 + 고객 포털 + 관리자 화면 골격의 첫 버전입니다.
Next.js(App Router) + TypeScript + Tailwind CSS로 제작했습니다.

## 실행 방법 (로컬)

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속. (프로덕션 빌드 확인은 `npm run build && npm run start`)

## 페이지 구성

- `/` — 메인: 지역 메시지, 무료 견적/AS·토너 접수/고객 로그인 버튼, 서비스 강점, 사무실 규모별 추천, 설치사례·후기, 상담 유도
- `/products` — 흑백/컬러 복합기·프린터 렌탈 상품 목록 (월 렌탈료는 전부 **샘플 가격**)
- `/quote` — 무료 견적 요청 폼 (인원수 / 월 출력량 / 컬러 사용여부 / 연락처)
- `/support` — 비로그인 AS·토너 접수 폼
- `/login` — 로그인 화면 (데모 모드로 고객/관리자 화면 전환 가능)
- `/portal/*` — 고객 포털: 대시보드, 내 기기, 계약 정보, AS·토너 접수 및 내역
- `/admin/*` — 관리자 화면: 대시보드, 고객 관리, 상품 관리, 접수·방문 일정

## 로그인/인증에 대해 (중요)

- 현재 로그인은 **데모용 목업**입니다. 입력한 비밀번호는 어디에도 저장·전송되지 않고 즉시 버려집니다.
  (`lib/mock-auth.ts` 참고 — 이메일과 역할만 브라우저 `localStorage`에 저장)
- 실제 서비스 적용 시 **Supabase Auth**(이메일/비밀번호, 매직링크 등)로 교체하는 것을 전제로 화면 흐름만
  미리 만들어 둔 구조입니다. `lib/mock-auth.ts`와 `/login`, `/portal`, `/admin`의 인증 체크 부분만
  Supabase 클라이언트 호출로 교체하면 됩니다.
- `/portal`, `/admin` 진입 시 로그인 세션이 없으면 자동으로 `/login`으로 이동합니다.

## 데이터에 대해 (중요)

`lib/data.ts`의 모든 값(가격, 후기, 설치사례, 고객/기기/일정 목록)은 **화면 구성용 샘플 데이터**입니다.
실제 서비스 오픈 전 반드시 실제 값으로 교체해야 하며, 화면에도 "샘플/예시" 배지를 표시해 실제 사실처럼
오인되지 않도록 했습니다.

## 이번 버전에서 하지 않은 것

- 배포(호스팅), 외부 서비스 계정 생성, 실제 고객 데이터 입력은 하지 않았습니다.
- 실제 인증/DB 연동(Supabase 등), 결제, 알림(문자/이메일 발송)은 연결되어 있지 않습니다.
- 회사 소개(사업자등록번호, 실제 연락처, 실제 후기/설치사례)는 아직 반영되지 않았습니다.

## 다음 단계에서 사용자가 결정/준비해야 할 것

1. **Supabase 프로젝트 생성 여부** — 고객/관리자 인증, 상품·계약·접수 데이터를 저장할 백엔드로 Supabase를
   사용할지 확정이 필요합니다. (계정 생성은 사용자가 직접 진행)
2. **실제 사업 정보** — 대표 연락처, 사업자등록번호, 주소, 상담 가능 시간 등 (현재 자리만 마련해둠)
3. **실제 렌탈료 정책** — 기종별 실제 월 렌탈료, 계약 조건(약정기간, 유지비 포함 여부 등)
4. **실제 설치사례/고객 후기** — 공개 동의를 받은 사례만 게시 (현재는 전부 예시 문구)
5. **관리자 권한 정책** — 관리자 계정을 누가 몇 명 가질지, 고객 정보 접근 범위
6. **AS/토너 접수 처리 흐름** — 접수 후 담당자 배정, 알림(문자/카카오톡 등) 방식
7. **배포 방식** — Vercel 등 호스팅 서비스 선택 (요청 시 별도로 진행 가능)

## 폴더 구조 요약

```
app/                # 페이지 (App Router)
  page.tsx           # 메인
  products/          # 렌탈 상품
  quote/              # 견적 요청
  support/            # 비로그인 AS·토너 접수
  login/               # 로그인
  portal/              # 고객 포털 (레이아웃 + 대시보드/기기/계약/AS)
  admin/               # 관리자 화면 (레이아웃 + 대시보드/고객/상품/일정)
components/         # 공통 UI (헤더, 푸터, 대시보드 셸)
lib/
  data.ts             # 샘플 데이터
  mock-auth.ts        # 데모 로그인 (Supabase 연동 전 임시)
```
